# Enterprise-Campus-Network
Created an Enterprise Campus Network to test and demonstrate CCNA networking concepts. Implemented multiple VLANs, Inter-VLAN Routing, DHCP with an 8-hour lease, EIGRP, Default Routing, VRRP for Layer 3 redundancy, STP for Layer 2 redundancy, Port Security, NAT, and PAT with end-to-end connectivity testing.

1. VLAN & Inter-VLAN Routing

Implemented multiple VLANs for network segmentation and configured Inter-VLAN Routing to enable communication between different VLANs.

2. EIGRP & Default Routing

Configured EIGRP with AS 10 for dynamic routing between network segments and implemented default routing for external network connectivity.

3. DHCP & IP Address Management

Configured a DHCP server for automatic IP address allocation and implemented an 8-hour DHCP lease time for client devices.

4. STP & VRRP Redundancy

Implemented STP for Layer 2 redundancy and VRRP for Layer 3 gateway redundancy to improve network availability and prevent connectivity failures.

5. NAT/PAT & Port Security

Configured NAT/PAT for communication between private and external networks and implemented Port Security to control access to switch ports.
